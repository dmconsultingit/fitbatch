# FitBatch logo — usage guide

The FitBatch mark is a **stack of activity files**; the front file shows a **structured workout**
(warm-up, two intervals, a rest, cool-down). It says, in one picture: sport, data, training plans
and a whole batch at once.

## Files

| Use | File |
|---|---|
| Symbol (both themes) | `fitbatch-symbol.svg` |
| Symbol, 16–48 px | `fitbatch-symbol-small.svg` |
| Horizontal logo on dark / light | `fitbatch-horizontal-on-dark.svg` / `fitbatch-horizontal-on-light.svg` |
| Stacked logo on dark / light | `fitbatch-stacked-on-dark.svg` / `fitbatch-stacked-on-light.svg` |
| One colour | `fitbatch-horizontal-black.svg`, `fitbatch-horizontal-white.svg`, `fitbatch-symbol-black.svg`, `fitbatch-symbol-white.svg`, `fitbatch-symbol-mono-ea580c.svg` |
| App / taskbar / `.exe` icon | `fitbatch.ico` (16–256 px), `fitbatch-symbol-app-icon.svg` |
| macOS app icon | `fitbatch.icns` (16–1024 px), `fitbatch-macos-icon.svg` (tile with the standard macOS margin) |
| Website icons | `web/` (favicon.ico/svg, apple-touch-icon, 192/512, maskable, manifest, `<head>` snippet) |
| Presentation | `presentation/slide-01…05.png` |

All logo files are pure vector paths: the wordmark is outlined from **Barlow Semi Condensed Bold**
(SIL Open Font License), so no font is needed to display it.

## Rules

- **Clear space:** keep free space around the logo at least the width of one stack band
  (≈ 1/12 of the symbol height) on every side.
- **Minimum size:** symbol 16 px (use the small version below 48 px); horizontal logo 96 px wide.
- **Backgrounds:** use the `on-dark` file on dark backgrounds, `on-light` on light ones; on photos
  or busy backgrounds use the one-colour white or black version.
- **Do not:** recolour the parts, add effects (shadows, gradients, outlines), stretch or rotate,
  rearrange the symbol and the wordmark, or set "FitBatch" in another typeface.
- **Trademarks:** FitBatch is independent and not affiliated with Garmin or other platforms; never
  combine the logo with their marks in a way that suggests endorsement.
